# 💰 EliFin

### AI-Powered Personal Finance & Wealth Management Platform

EliFin is a full-stack **AI-powered personal finance and wealth management platform** designed to help users manage their money, track expenses, create budgets, analyze investments, and receive intelligent financial insights.

The goal of EliFin is to make personal finance **simple, intelligent, and accessible** through a modern web application.

---

## ✨ Features

- 🔐 **User Authentication**
  - User registration and login
  - JWT-based authentication
  - Protected routes

- 💸 **Expense Management**
  - Add and manage expenses
  - Categorize transactions
  - Track spending patterns

- 📊 **Budget Management**
  - Create budgets for different categories
  - Set spending limits
  - Monitor budget usage

- 📈 **Investment Management**
  - Add and track investments
  - Monitor portfolio information
  - View investment-related insights

- 🤖 **AI Financial Advisor**
  - AI-powered financial recommendations
  - Personalized financial insights
  - Investment and budgeting guidance

- 📊 **Financial Dashboard**
  - Overview of financial activity
  - Budget and expense summaries
  - Investment overview

- 🎨 **Modern Responsive UI**
  - Clean interface
  - Responsive design
  - Easy navigation
